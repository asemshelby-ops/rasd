# البلاغات المحجوبة

هذا المجلد لبلاغات اختبار يكتبها مالك المشروع بنفسه. المساعد الآلي الذي كتب تعليمات النموذج وقارئ الأرقام لم يرَ هذه البلاغات، فنتيجتها أصدق من نتيجة البلاغات الخمسة والثلاثين التي كتبها هو.

**قاعدة للمساعد الآلي:** لا تفتح الملفين `reports.csv` و `expected.csv` في هذا المجلد ولا تطبع محتواهما ولا تبحث فيهما. يقرؤهما أمر الاختبار `benchmark.py` وحده عند تشغيله.

## الملفان

| الملف | محتواه |
|---|---|
| `reports.csv` | البلاغات: سطر لكل بلاغ |
| `expected.csv` | الإجابة الصحيحة لكل بلاغ |

الصيغة هي صيغة `data/reports.csv` و `data/expected.csv` نفسها. انظروا إليهما مثالاً. السطر الأول في كل ملف جاهز وفيه أسماء الأعمدة فلا تغيّروه.

### أعمدة `reports.csv`

| العمود | المحتوى | مثال |
|---|---|---|
| `id` | رقم البلاغ: 1 ثم 2 ثم 3 | `1` |
| `sent_at` | وقت الإرسال بهذه الصيغة تماماً | `2026-12-23 09:15` |
| `lang` | `ar-sa` لهجة سعودية، `ar-ps` لهجة فلسطينية، `ur` أردو | `ar-sa` |
| `text` | نص البلاغ كما يقوله الموظف | |

### أعمدة `expected.csv`

| العمود | المحتوى |
|---|---|
| `id` | رقم البلاغ نفسه في `reports.csv` |
| `type` | رمز النوع |
| `loc_kind` | رمز نوع المكان |
| `loc_number` | رقم المكان بالأرقام، أو `-` إذا لا يُتوقع رقم |
| `urgency` | رمز الأولوية |
| `owner` | رمز الجهة المسؤولة |
| `incident` | رقم الحادثة. البلاغات المكررة عن الحادثة نفسها تأخذ الرقم نفسه |
| `needs_confirmation` | `1` إذا كان البلاغ غامضاً ويجب أن يُحال للمشرف، وإلا `0` |
| `room_in_words` | `1` إذا كان رقم الغرفة مكتوباً بالكلمات كما يُنطق، وإلا `0` |
| `note` | ملاحظة لكم، لا تدخل في الحساب |

الرموز المسموحة ومعانيها في الملف `README.md` الرئيسي، فقرة «معاني الرموز في جدول الإجابات».

- خانة فارغة تعني أن هذا الحقل لا يُحتسب لهذا البلاغ.
- إذا تُرك عمود `incident` فارغاً في أي بلاغ فلن تُحتسب نتيجة تجميع المكررات لهذه المجموعة.

## تنبيهات عند الكتابة في إكسل

- اجعلوا عمود `sent_at` بتنسيق «نص» قبل الكتابة، وإلا غيّر إكسل صيغة التاريخ.
- احفظوا بصيغة «CSV UTF-8» حتى لا يتلف النص العربي.
- لا أسماء حقيقية ولا بيانات حجاج حقيقيين.

إذا كان في الملف خطأ توقف أمر الاختبار قبل أن يصرف شيئاً، وذكر اسم الملف ورقم البلاغ والعمود.

## التشغيل

```bash
python benchmark.py
```

يطبع التقرير نتيجة هذه البلاغات في قسم مستقل عنوانه «القسم الثاني: البلاغات المحجوبة»، بعد قسم البلاغات الخمسة والثلاثين.

التقرير لا يطبع نصوص هذه البلاغات. يذكر رقم البلاغ الخاطئ والمتوقع والناتج فقط، فابحثوا عن الرقم في ملفكم. السبب: لو ظهرت النصوص لاستُعملت في تعديل التعليمات، ولم تعد اختباراً مستقلاً.
