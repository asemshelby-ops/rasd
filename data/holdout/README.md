# البلاغات المحجوبة

هذا المجلد لبلاغات اختبار يكتبها مالك المشروع وفريقه. المساعد الآلي الذي كتب تعليمات النموذج وقارئ الأرقام لا يرى هذه البلاغات، فنتيجتها أصدق من نتيجة البلاغات التي كتبها هو.

**قاعدة للمساعد الآلي:** لا تفتح الملفين `reports.csv` و `expected.csv` في هذا المجلد ولا تطبع محتواهما ولا تبحث فيهما ولا تعرض قائمة بمحتوى المجلد. يقرؤهما أمر الاختبار `benchmark.py` وحده عند تشغيله. الملف الوحيد الذي يجوز تعديله هنا هو هذا الشرح.

**كل ما يُكتب هنا خيالي:** لا أسماء حجاج حقيقية، ولا أرقام جوازات أو تأشيرات حقيقية، ولا صور.

## اكتبوا البلاغ كما يُكتب في الواقع

البلاغات الحقيقية تأتي من جوالات الموظفين في مجموعة واحدة تُستعمل لكل شيء. كل موظف يكتب ما يخطر له. فاكتبوا بلاغاتكم بالفوضى نفسها، ولا ترتّبوها:

- اسم الحاج أولاً غالباً، ثم المشكلة، ثم الفندق، وأحياناً الغرفة.
- الحقول بأي ترتيب، بنقاط أو شرطات أو بلا ترقيم.
- وجوه تعبيرية، وأرقام عربية مثل `٤١٢` وأرقام مثل `412` في الرسالة نفسها.
- أرقام الغرف بالكلمات كما تُنطق: «أربعمية وطنعش».
- بلاغ فيه فندق بلا غرفة، وبلاغ فيه صورة فقط.
- رسائل ليست بلاغات أصلاً: تحضير، ملاحظات اجتماع، ملف مرفق، دردشة، أو ردّ مثل «لقيناها 👍».

## الملفان

| الملف | محتواه |
|---|---|
| `reports.csv` | الرسائل: سطر لكل رسالة |
| `expected.csv` | الإجابة الصحيحة لكل رسالة |

السطر الأول في كل ملف فيه أسماء الأعمدة. الأعمدة الأساسية موجودة فيه فلا تحذفوها. الأعمدة الاختيارية تضيفونها أنتم إلى السطر الأول إن أردتم احتسابها.

### أعمدة `reports.csv`

| العمود | المحتوى | مثال |
|---|---|---|
| `id` | رقم الرسالة: 1 ثم 2 ثم 3 | `1` |
| `sent_at` | وقت الإرسال بهذه الصيغة تماماً | `2026-12-23 09:15` |
| `lang` | `ar-sa` لهجة سعودية، `ar-ps` لهجة فلسطينية، `ur` أردو | `ar-sa` |
| `text` | نص الرسالة كما كتبها الموظف | |
| `photo` (اختياري) | `1` إذا كان مع الرسالة صورة. عندها يجوز أن يكون النص فارغاً | `1` |

### أعمدة `expected.csv` الأساسية

| العمود | المحتوى |
|---|---|
| `id` | رقم الرسالة نفسه في `reports.csv` |
| `type` | رمز النوع من الجدول أدناه |
| `loc_kind` | نوع المكان: `room` غرفة، `elevator` مصعد، `floor` دور، `common_area` مرفق عام، `none` غير مذكور |
| `loc_number` | رقم الغرفة أو الدور أو المصعد بالأرقام، أو `-` إذا لا يُتوقع رقم |
| `urgency` | الأولوية: `critical` حرج، `urgent` عاجل، `medium` متوسط، `normal` عادي |
| `owner` | الجهة المسؤولة من جدول الأنواع أدناه |
| `incident` | رقم الحادثة. الرسائل المكررة عن الحادثة نفسها تأخذ الرقم نفسه |
| `needs_confirmation` | `1` إذا كان يجب أن يُحال البلاغ للمشرف، وإلا `0` |
| `room_in_words` | `1` إذا كان رقم الغرفة مكتوباً بالكلمات كما يُنطق، وإلا `0` |

### أعمدة `expected.csv` الاختيارية

| العمود | المحتوى |
|---|---|
| `hotel` | اسم الفندق كما في الرسالة دون كلمة «فندق»، أو `-` إذا لم يُذكر |
| `name` | اسم الحاج كما كُتب في الرسالة، أو `-` إذا لم يُذكر |
| `risks` | رموز المخاطر التي تذكرها الرسالة صراحة، بينها مسافة، مثل `elderly sick` |
| `partial` | `1` إذا قالت الرسالة صراحة إن العطل جزئي أو إن الشيء ما زال يعمل |
| `ask` | الحقل الذي يجب أن يسأل رصد المرسلَ عنه: `type` أو `place` أو `hotel` أو `name`، أو `-` إذا لا سؤال |
| `note` | ملاحظة لكم، لا تدخل في الحساب |

خانة فارغة تعني أن هذا الحقل لا يُحتسب لهذه الرسالة. وإذا تُرك عمود `incident` فارغاً في أي رسالة فلن تُحتسب نتيجة تجميع المكررات.

## الأنواع وأولويتها

الأولوية لا تُكتب باجتهاد. تؤخذ من جدول الفريق، **لمرحلة «أيام مكة»**:

| الرمز | المعنى | الأولوية الأساسية | الجهة المسؤولة |
|---|---|---|---|
| `lost_pilgrim` | حاج تائه أو لا يستطيع التواصل | `critical` | `pilgrim_affairs` |
| `health` | حالة صحية: حاج مريض أو مصاب، وهذا موضوع البلاغ | `critical` | `pilgrim_affairs` |
| `nusuk_card` | بطاقة نسك مفقودة أو تالفة | `urgent` | `pilgrim_affairs` |
| `no_nusuk_card` | حاج ليست له بطاقة نسك أصلاً | `urgent` | `pilgrim_affairs` |
| `ac` | عطل تكييف | `urgent` | `maintenance` |
| `water` | انقطاع الماء | `urgent` | `maintenance` |
| `power_elevator` | عطل كهرباء أو مصعد | `urgent` | `maintenance` |
| `luggage` | أمتعة لم تصل | `medium` | `luggage_team` |
| `forgot_credentials` | نسي الحاج كلمة مرور التطبيق أو رقم جوازه | `medium` | `pilgrim_affairs` |
| `cleaning` | نظافة الغرفة | `normal` | `housekeeping` |
| `gifts` | هدايا أو توزيعات لم تُستلم | `normal` | `pilgrim_affairs` |
| `unclear` | بلاغ لا يُعرف ما مشكلته | `urgent` | `supervisor` |
| `not_a_report` | ليست بلاغاً: تحضير، اجتماع، ملف، دردشة، ردّ | اتركوها فارغة | `nobody` |

ثم تُعدَّل الأولوية الأساسية هكذا:

1. **العطل الجزئي ينزل درجة.** إذا قالت الرسالة صراحة إن عطل التكييف أو الماء أو الكهرباء أو المصعد جزئي، أو إن الشيء ما زال يعمل، فالأولوية «متوسط» بدل «عاجل». ضعوا `1` في عمود `partial`.
2. **كل خطر مذكور صراحة يرفعها درجة، حتى «حرج».** المخاطر ستة:

| الرمز | الخطر |
|---|---|
| `elderly` | حاج كبير في السن |
| `sick` | حاج مريض، أو مرض أو عَرَض مذكور |
| `medication` | دواء حاج |
| `time_limit` | موعد قريب، كخروج المجموعة أو رحلة |
| `alone_or_lost` | حاج وحده أو تائه |
| `danger` | خطر جسدي مباشر: عالقون في مصعد مثلاً، أو حريق أو دخان أو شرر أو رائحة حريق |

مثال: أمتعة لم تصل `medium`، فإن ذكرت الرسالة أن في الحقيبة دواء صارت `urgent`. الحر أو طول الانتظار أو غضب الحاج ليس خطراً ما لم تذكر الرسالة أحد الستة.

في أيام الحج تصير بطاقة نسك المفقودة أو غير الموجودة `critical`، لكن اختبار الدقة يحسب دائماً بمرحلة «أيام مكة»، فاكتبوا الأولوية على هذا الأساس.

## متى يُحال البلاغ للمشرف؟

ضعوا `1` في `needs_confirmation` إذا تحقق واحد من هذه:

- نوع البلاغ غير واضح.
- عطل أو طلب نظافة بلا غرفة ولا دور ولا مرفق معروف.
- بلاغ من الأنواع الأخرى لا فندق فيه ولا غرفة.
- بطاقة نسك أو كلمة مرور أو أمتعة أو هدايا، ولا يُعرف لمن: لا اسم ولا غرفة.

بلاغ بطاقة نسك فيه اسم الحاج وفندقه بلا غرفة **لا يُحال للمشرف**.

والرسالة التي ليست بلاغاً لا تُحال للمشرف: ضعوا `0`.

## تنبيهات عند الكتابة في إكسل

- اجعلوا عمود `sent_at` بتنسيق «نص» قبل الكتابة، وإلا غيّر إكسل صيغة التاريخ.
- احفظوا بصيغة «CSV UTF-8» حتى لا يتلف النص العربي.

إذا كان في الملف خطأ توقف أمر الاختبار قبل أن يصرف شيئاً، وذكر اسم الملف ورقم الرسالة والعمود، دون أن يطبع محتوى الخانة.

## التشغيل

```bash
python benchmark.py
```

يطبع التقرير نتيجة هذه البلاغات في قسم مستقل عنوانه «القسم الثاني: البلاغات المحجوبة»، بعد قسم البلاغات الأساسية.

التقرير لا يطبع نصوص هذه البلاغات ولا أسماء الحجاج فيها. يذكر رقم الرسالة الخاطئة والمتوقع والناتج فقط، فابحثوا عن الرقم في ملفكم. السبب: لو ظهرت النصوص لاستُعملت في تعديل التعليمات، ولم تعد اختباراً مستقلاً.
